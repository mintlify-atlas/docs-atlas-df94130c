Claude Resume Kit is a Claude Code-powered toolkit built for researchers and engineers who have lots of source material — papers, codebases, reports — and apply to many positions across different employer types. Unlike tools that rewrite a pasted resume, this kit builds a verified knowledge base from your actual work, then draws on it for every new application. It knows which papers are published versus under review, who did which parts of the work, and how to frame the same achievement differently for a faculty search versus an industry R&D role.

## How it works

The kit has two phases: a one-time knowledge base setup, and a per-application generation loop. The table below shows the full pipeline from raw papers to a finished, critique-verified package.

| Stage | Command | Input | Output |
|-------|---------|-------|--------|
| Extract papers | `/setup-extract <paper-path>` | PDF or `.tex` source | `knowledge_base/extractions/*.md` |
| Build knowledge base | `/setup-build-kb` | All extractions | Experience files, bundles, support files |
| Generate resume or CV | `/make-resume <jd-path>` | Job description | `output/<Folder>/e2e_*.tex` + session file |
| Generate cover letter | `/make-cl [session-file]` | Session file | `output/<Folder>/*_cover_letter.tex` |
| Critique package | `/critique [session-file]` | Session file + `.tex` files | `output/<Folder>/critique_*.md` |
| Refine from feedback | `/edit-resume <tex-path> [critique-path]` | `.tex` + critique | Updated `.tex` files |

The `/make-resume`, `/make-cl`, and `/critique` steps each run in a **separate Claude Code session** — fresh context produces better quality, and critique especially benefits from not having seen the generation process.

## The six skills

Each skill is a Claude Code slash command defined in `.claude/skills/<name>/SKILL.md`. They load the shared knowledge base and enforce the same accuracy rules.

| Skill | Purpose | Input | Output |
|-------|---------|-------|--------|
| `/setup-extract` | Extract structured data from a paper | Paper path | `knowledge_base/extractions/*.md` |
| `/setup-build-kb` | Synthesize KB from all extractions | All extractions | `resume_builder/{experience,bundles,support}/` |
| `/make-resume` | Generate tailored resume or CV | JD path | `output/<Folder>/e2e_*.tex` + session file |
| `/make-cl` | Generate matching cover letter | Session file | `output/<Folder>/*_cover_letter.tex` |
| `/critique` | Independent quality review | Session file | `output/<Folder>/critique_*.md` |
| `/edit-resume` | Edit resume/CV/CL from feedback | `.tex` + critique | Updated `.tex` files |
