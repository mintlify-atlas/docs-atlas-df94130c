Claude Resume Kit is a Claude Code-powered toolkit built for researchers and engineers with rich source material — papers, codebases, reports — who apply to many positions across different employer types. You extract your work once into a verified knowledge base, then point the system at any job description to generate a tailored LaTeX resume, cover letter, and scored critique.

## What makes this different

Most AI resume tools work the same way: paste resume + paste JD, get a rewrite. They don't know which of your papers is published vs. under review. They'll upgrade "contributed to" into "developed" without blinking.

Claude Resume Kit is different by design:

## How it works

<Steps>
  <Step title="Extract your papers (one-time)">
    Drop your PDFs or `.tex` source files into `knowledge_base/papers/` and run `/setup-extract` on each. Claude reads the paper and asks structured questions about your contributions, publication status, and what to include or exclude.
  </Step>
  <Step title="Build your knowledge base (one-time)">
    Run `/setup-build-kb` to synthesize all extractions into experience files, role-type bundles, and skills taxonomy — the verified foundation every application draws from.
  </Step>
  <Step title="Generate for a job">
    Drop the job description into `JDs/` and run `/make-resume JDs/target_job.txt`. Approve the bullet plan, get a `.tex` file. Then run `/make-cl` for the cover letter and `/critique` for a scored review — each in a fresh session.
  </Step>
  <Step title="Compile and submit">
    Run `pdflatex` on the generated `.tex` files to produce PDFs. No LaTeX knowledge required — the templates handle all formatting.
  </Step>
</Steps>

## The six skills

| Skill | What it does | Input | Output |
|-------|-------------|-------|--------|
| `/setup-extract` | Extract structured data from a paper | Paper path | `knowledge_base/extractions/*.md` |
| `/setup-build-kb` | Build KB from extractions | All extractions | `resume_builder/{experience,bundles,support}/` |
| `/make-resume` | Generate tailored resume or CV | JD path | `output/<Folder>/e2e_*.tex` + session file |
| `/make-cl` | Generate matching cover letter | Session file | `output/<Folder>/*_cover_letter.tex` |
| `/edit-resume` | Edit resume/CV/CL from feedback | Session + feedback | Updated `.tex` files |
| `/critique` | Independent quality review | Session file | `output/<Folder>/critique_*.md` |
